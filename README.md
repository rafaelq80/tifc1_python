# Projetos de introdução à programação com Python

Este repositório reúne cinco projetos práticos para aprender conceitos básicos de programação em Python. Os exercícios avançam de programas simples de saída para entrada de dados, listas, decisões e funções.

## Projetos

| Pasta | Projeto | Conceitos praticados |
|---|---|---|
| [`01_helloworld`](./01_helloworld/) | Hello World e poema do Python | Saída de dados, primeiro programa e importação de módulos |
| [`02_code_toy`](./02_code_toy/) | A História Maluca (Mad Lib) | Entrada de dados, variáveis e composição de texto |
| [`03_shopping_list`](./03_shopping_list/) | Lista de Compras | Listas e organização de valores |
| [`04_calculadora_simples`](./04_calculadora_simples/) | Calculadora Simples | Operações aritméticas, tipos de dados e decisões |
| [`05_calculadora_aprimorada`](./05_calculadora_aprimorada/) | Calculadora Aprimorada | Funções, listas numéricas, fluxo de controle e verificação de números |

Cada pasta contém um README com o contexto, os requisitos e exemplos específicos do exercício.

## Como começar

1. Instale o Python 3.
2. Escolha um projeto e consulte o README correspondente.
3. Abra um terminal na raiz do repositório e execute o arquivo indicado. Por exemplo:

   ```bash
   python 02_code_toy/main.py
   ```

   Em projetos que solicitam informações, digite as respostas no terminal. O projeto Hello World contém `Hello.py` e também o exercício extra `Poema.py`; a calculadora aprimorada usa funções definidas em `main.py`.

Os projetos não requerem bibliotecas externas: usam Python e seus recursos padrão.
